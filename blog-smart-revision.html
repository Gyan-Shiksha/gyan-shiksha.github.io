Revision

Smart Revision કેવી રીતે કરવી?

Revisionનો અર્થ એક જ chapter વારંવાર વાંચવો નથી. સાચી revisionમાં recall, short repetition અને weak-topic correction સામેલ હોય છે.

Gyan Shiksha EditorialEvergreen GuideReviewed 7 Oct 2026

1. Book બંધ કરીને યાદ કરો

Chapter વાંચ્યા પછી તરત ફરી reading શરૂ ન કરો. Book બંધ કરો અને paper પર headings, formulas, definitions અથવા key points લખવાનો પ્રયાસ કરો. જ્યાં અટકો ત્યાં learning gap છે. પછી માત્ર એ ભાગ ફરી વાંચો.

2. Short Revision Cycle બનાવો

એક જ દિવસે લાંબી revision કરતાં નાના intervals ઉપયોગી રહે છે. આજે શીખેલું કાલે થોડું revise કરો, પછી થોડા દિવસ પછી અને પછી એક અઠવાડિયા પછી. દરેક review ટૂંકો પણ active હોવો જોઈએ.

3. Weak Topic List રાખો

“Maths weak છે” એવું broad લખવાને બદલે exact topic લખો: percentage word problems, linear equation steps, grammar tense confusion વગેરે. Exact problem દેખાય ત્યારે exact practice શક્ય બને છે.

4. Mix Practice કરો

એક જ પ્રકારના 20 પ્રશ્નો કર્યા પછી answer pattern યાદ થઈ શકે છે. અલગ chapters અથવા question types mix કરીને practice કરવાથી actual understanding ચકાસાય છે.

Revision Formula

Read less → Recall more → Practice → Check mistakes → Repeat weak areas.

5. Short Notes ખરેખર short રાખો

જો short notes textbook જેટલા લાંબા થઈ જાય તો revision માટે તેમનો ફાયદો ઓછો થાય છે. One-page summary, formula list, diagram labels, vocabulary અથવા “મારે શું ભૂલાય છે?” જેવી compact sheet વધુ useful છે.

6. Revision Sessionનો અંત self-checkથી કરો

Session પૂરો કરતાં પહેલાં 3–5 પ્રશ્નો જાતે બનાવો અથવા Quiz Saathiમાં related practice કરો. જો explanation વગર answer આપી શકો તો topicની memory મજબૂત થઈ રહી છે.

Smart revisionનો મુખ્ય હેતુ hours વધારવો નથી; દરેક minuteમાં learning quality વધારવી છે.
