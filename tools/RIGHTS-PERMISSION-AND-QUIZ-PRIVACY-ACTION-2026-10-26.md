### Publisher નિર્ણયનું સંક્ષિપ્ત ધોરણ

| પરિસ્થિતિ | સલામત આગળનું પગલું |
|---|---|
| સ્પષ્ટ open licence અને mirror redistribution મંજૂર | licence/attribution/versionના પુરાવા સાથે upload link રાખી શકાય |
| PDFમાં written-permission requirement | **પરવાનગી મળ્યા સુધી “મંજૂર” નહીં ગણવી**; અધિકૃત original PDF/download landing page તરફ ફેરવવાનો વિકલ્પ શોધવો |
| અધિકારધારક/Terms અસ્પષ્ટ | publication URL અને licence શરતોનો પુષ્ટિદાયક જવાબ મેળવો; એક public noticeને blanket grant ન માનો |
| third-party/NCERT-derived text | source publisher અને underlying rights holderની જુદી શરતો તપાસો |
| પ્રશ્નપત્ર | પરીક્ષાનું જાહેર પ્રશ્નપત્ર વિદ્યાર્થીઓને ઉપલબ્ધ હોવું અને તેને પોતાની જાહેરાતવાળી સાઇટ મારફતે rehost કરવાનો અધિકાર એકસરખો નથી |

## B. Quiz Saathi — privacy માટે હવે કયો પુરાવો મળ્યો અને શું બાકી

- Connected Google Sheetsમાં `Student_Scores` ટેબમાં કેટલાક **અગાઉના** વિદ્યાર્થીનું નામ અને શાળા ધરાવતા rows છે; names/score આ public reportમાં નહીં મૂકી શકાય.
- Drive permission metadataમાં માત્ર user-type owner અને writer બતાવાયા હતા; public `anyone` grants દેખાયા ન હતા. છતાં Apps Script Web App પબ્લિક endpoint અથવા public aggregate data exposure આ permissionsથી સંપૂર્ણ ચકાસાતા નથી.
- Google Drive searchમાં Quiz Applicationના ઘણાં **Sheet backups** મળ્યા, પરંતુ હાલના deployed Google Apps Scriptનો `Code.gs`/project source **મળ્યો નથી**. તેથી અત્યારે `saveScore`, `doPost`, result writes, anonymous ID, access scope અથવા delete job વિશે ખાતરી આપી શકાતી નથી.

### Live Apps Script code મળ્યા પછી non-destructive QA

1. Web Appનો સાચો deployment અને bound Spreadsheet ID મળાવો.
2. Quiz UI → Submit → `doPost`/`google.script.run` → `Student_Scores` સુધી exact data flow map કરો.
3. કયા fields જરૂરી/optional છે અને કયા identifier માટે business purpose છે તે નક્કી કરો; score રાખવો હોય પણ ઓળખ જરૂરી ન હોય તો anonymized attempt IDsનો વિકલ્પ બનાવો.
4. હાલના અગાઉના વિદ્યાર્થી recordsમાં ફેરફાર કર્યા વગર test-only sample attempt વડે write/storage, authorised viewers, delete request, retentionની પ્રક્રિયા validate કરો.
5. Retention policy અને બાળકો માટે યોગ્ય age/parent-guardian/ads treatment owner સાથે નક્કી કર્યા પછી જ production code બદલો.
