Privacy Policy

Gyan Shiksha પર કઈ માહિતી લેવામાં આવે છે અને તેનો ઉપયોગ કેવી રીતે થાય છે તેની સરળ સમજ.

Last updated: 7 October 2026

Quiz Saathiમાં લેવામાં આવતી માહિતી

Quiz શરૂ કરતી વખતે વિદ્યાર્થી પોતે દાખલ કરે તે School Name અને Student Name, તેમજ પસંદ કરેલ Standard, Section/Class, Subject, Chapter, Difficulty, question count અને quiz attempt/score જેવી માહિતી Google Apps Script દ્વારા process થઈ શકે છે અને Google Sheetsમાં record થઈ શકે છે.

આ માહિતી શા માટે?

Quiz ચલાવવા, વિદ્યાર્થીનો attempt/score record રાખવા, question-bank usage સમજવા અને educational performance reports માટે આ માહિતીનો ઉપયોગ થઈ શકે છે.

શું લેવામાં આવતું નથી?

હાલના Quiz Saathi flowમાં password, payment card information અથવા home address માંગવાનો હેતુ નથી. આવી sensitive information કોઈ quiz fieldમાં દાખલ ન કરવી.

Educational Games & Local Storage

Educational Gamesમાં best score તમારા browserના local storageમાં locally save થઈ શકે છે. આ score Gyan Shiksha server અથવા Quiz Google Sheetમાં મોકલાતો નથી. Browser data clear કરશો તો local best score દૂર થઈ શકે છે.

Hosting & Google Services

Main website GitHub Pages પર host થાય છે અને Quiz backend Google Apps Script/Google Sheets પર ચાલે છે. તેથી website અથવા quiz ઉપયોગ કરતી વખતે hosting/service providers standard technical request information process કરી શકે છે.

Third-party media

કેટલાક visual images third-party image CDN પરથી load થઈ શકે છે. આવા requests સંબંધિત provider સુધી technical request information પહોંચાડી શકે છે. શક્ય હોય ત્યાં production assetsને local રાખવાની દિશામાં site optimize કરવામાં આવે છે.

Advertising

હાલ વેબસાઇટ પર Google AdSense જાહેરાતો સક્રિય નથી.

Corrections & Contact

Privacy અથવા stored quiz information સંબંધિત પ્રશ્ન માટે Contact pageનો ઉપયોગ કરો. અમારો સંપર્ક ઈમેલ gyanshikshaa@gmail.com છે.
