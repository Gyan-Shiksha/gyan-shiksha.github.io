Security

Security & Responsible Reporting

Gyan Shikshaની static-first architecture, secret-handling rules અને security issue report કરવાની રીત.

Last updated: 7 October 2026

Static-first website

Main website GitHub Pages પર static HTML, CSS અને JavaScript તરીકે deploy થાય છે. Password/database credentials અથવા private server secrets frontend codeમાં રાખવાના નથી.

Quiz backend

Quiz Saathi Google Apps Script અને Google Sheets પર ચાલે છે. Public Web App URL websiteમાં embed થઈ શકે છે, પરંતુ API keys, private tokens, account credentials અથવા restricted Sheet secrets frontendમાં publish ન કરવા.

Responsible reporting

Security issue જણાય તો public comment/issueમાં sensitive details post ન કરો. Contact page પરથી page URL, issue summary અને reproduce કરવાની safe steps મોકલો.

Scope

Helpful reportsમાં broken access control, unintended data exposure, secret leakage, unsafe redirects અથવા security-sensitive misconfiguration સામેલ હોઈ શકે છે. Availability testing અથવા disruptive automated traffic ન કરશો.
